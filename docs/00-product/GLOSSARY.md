# Глоссарий

| Термин | Значение |
|---|---|
| Барахолка | Раздел б/у инструментов от частных продавцов — весь объём MVP |
| Объявление, лот | Предложение одного инструмента одним продавцом |
| Модель | Запись справочника: бренд + модель + годы выпуска |
| Состояние | Одна из 8 ступеней (SPEC BR-02) |
| Предложение цены | Сумма ниже цены объявления, отправленная в чате |
| Цена согласована | Принятое предложение; дальше договорённость в чате |
| Итоговая цена | Сумма продажи, которую продавец указал при снятии объявления |
| Гейт | Контрольная точка релиза с чек-листом (`RELEASE-GATES.md`) |
| Эталон | PNG-снимок макета, с которым сравнивается реализация |
| ДС | Дизайн-система ЯМузыкант (`design/ds`) |
| OWNER | Владелец продукта — человек, подписывает гейты |
