# Модели агентов

## 1. Уровни

| Псевдоним | Модель (на 11.2026, сверить с актуальной линейкой) | Для чего |
|---|---|---|
| `opus` | Claude Opus — старшая модель линейки | Оркестратор; архитектура; state machines; безопасность, вход, ПДн; CI/CD и окружения; аудит гейтов; ревью задач `risk: high` |
| `sonnet` | Claude Sonnet — основная модель | Большинство задач: экраны, домен средней сложности, интеграции; ревью задач `risk: low/medium` |
| `haiku` | Claude Haiku — быстрая модель | Сиды, конфиги, тексты, простые страницы, документация, механические правки |

Псевдонимы сопоставляются с конкретными идентификаторами в одном месте — в настройках запуска агента. При выходе новых моделей меняется только эта таблица, карточки не трогаются.

## 2. Правило назначения

| Риск задачи | `model_impl` | `model_review` | Дополнительно |
|---|---|---|---|
| `low` | `haiku` или `sonnet` | `sonnet` | — |
| `medium` | `sonnet` | `sonnet` в новом контексте или `opus` | — |
| `high` | `opus` | `opus` в новом контексте | + человек (OWNER) на гейте |

Признаки `high`: вход и сессии, права и роли, ПДн, деньги (после MVP), state machines, удаление данных, CI/CD и production, безопасность загрузок, realtime-каналы.

## 3. Правила

- Ревьюер — всегда новый контекст без истории исполнителя: только карточка, diff, отчёты CI.
- Ревьюер не ниже исполнителя по уровню, кроме задач `low` (`haiku` → `sonnet`).
- Эскалация: после двух циклов `changes` исполнитель поднимается на уровень (`haiku → sonnet → opus`), отметка `escalations:` в карточке. Ревьюер остаётся прежним или повышается.
- Визуальная проверка (QA) — `sonnet` со скриншотами реализации и эталона.
- Оркестратор не понижает модель из карточки ради скорости. Повышать может, с записью причины.
