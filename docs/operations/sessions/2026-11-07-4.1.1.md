# Сессия 4.1.1

- Домен `app/Domain/Messaging`: StartConversation, SendMessage, MarkConversationRead, AnonymizeParticipant, ConversationPolicy, UnreadMessages, ConversationHistory, MessageBody

- Reverb: `laravel/reverb`, каналы `private-conversation.{id}` и `private-user.{id}`, события MessageSent, ConversationRead, UnreadCountChanged (очередь, после commit)

- e2e UC-D1: два контекста, доставка ≤ 2 с — прогнан локально с Reverb (зелёный)

## Решения
- Беседа создаётся только вместе с первым сообщением: пустых чатов у продавца нет
- Чужая беседа — 404 (в том числе до валидации текста), канал — 403 (критерий карточки)
- Писать в существующую беседу можно, только пока объявление в published (вопрос OWNER ниже)
- Лимит `messages` 30/мин на пользователя общий для новых бесед и ответов; антиспам — 4.1.3
- Вещатель `log` переопределён на null: Laravel подмешивает свои соединения в config/broadcasting.php
- Настройки клиента Reverb — из shared prop во время запроса, а не `VITE_*`: бандл CI собирается без них
