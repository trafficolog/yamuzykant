## Чек-лист выката на stage (накопленный)

- Удалить старый индекс Meilisearch `instrument_models` без префикса окружения (3.1.8, PR #129)
- При `SCOUT_QUEUE=true` индекс заполняется очередью после `scout:import` — смоук поиска через 1–2 мин после деплоя (3.1.8)
- Дозаполнить `listings.unpublished_at` для объявлений, ушедших на проверку после правки до миграции 4.1.4, если у них есть беседы (4.1.4)
- Задать `BROADCAST_CONNECTION=null`, пока не запущен Reverb (0.1.16)
- Перед миграцией `listings_one_draft_per_user` проверить дубли черновиков: `SELECT user_id FROM listings WHERE status='draft' GROUP BY user_id HAVING count(*)>1` (2.1.4)
- В `.env` stage `CACHE_STORE=redis`: на нём держатся метка «в сети» и частота писем `Cache::add` (4.4.1)
- До переключения кода на stage — `php artisan scout:sync-index-settings` (новый `sortableAttributes: id`, 3.1.12): иначе запросы с `sort: id:desc` падают и «Похожие» пусты
