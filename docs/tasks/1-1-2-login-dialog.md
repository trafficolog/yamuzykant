# 1.1.2. Окно входа

## Цель
Вход из шапки и при действии, которому нужен вход (написать, в избранное, продать).

## Что сделать
- `Components/LoginDialog` на компонентах ДС (Button, Field, Checkbox): шаг «Способ» — кнопка «Войти с Яндекс ID» и поле почты с «Получить код» → шаг «Код» (автоотправка при 6 цифрах, повтор через 60 с, «Изменить почту») → шаг «Первый вход»: имя (из Яндекс ID, если есть), город (по умолчанию из шапки), согласие с правилами и политикой ПДн со ссылками → готово
- Отличие от макета (пароль и тип аккаунта убраны) — уже в design/DEVIATIONS.md
- Открытие по кнопке «Войти» и по перехвату 401/419 с возвратом к действию
- Состояния: ввод, отправка, ошибка кода, блок, отказ Яндекса, первый вход, успех
