# 5.1.1. Автопроверки объявлений

## Цель
До появления консоли: объявления с контактами не публикуются, остальные признаки риска записываются для будущей очереди модерации (SPEC UC-L1, UC-O1).

## Что сделать
- Интерфейс `AutoCheck`; проверки: контакты в тексте (телефон, e-mail, мессенджеры), стоп-слова (справочник), дубль фото (pHash ≤ 6), цена < 60 % медианы по модели (при ≥ 5 sale_records)
- Синхронно при publish: контакты в тексте → отказ с подсказкой (SPEC UC-L1); стоп-слова — из конфига-сида до справочника 5.3.3
- Job после публикации: дубль фото, цена ниже рынка → флаги и риск `high|normal` в moderation_flags; с флагом `premoderation` — в moderation_queue

## Критерии приёмки
- [ ] Каждый признак срабатывает на фикстуре и не срабатывает на чистом объявлении
- [ ] Объявление с телефоном, e-mail или ссылкой на мессенджер не публикуется, пользователь видит причину у поля
- [ ] Флаги сохраняются с пояснением (показ модератору — 5.1.2)
- [ ] Definition of Done — AGENTS.md §3
