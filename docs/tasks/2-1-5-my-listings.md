# 2.1.5. Мои объявления: изменить, снизить цену, снять

## Цель
Продавец управляет своими объявлениями из кабинета.

## Что сделать
- Вкладка «Объявления»: фильтр по статусам, карточки со статусом и причиной возврата
- Действия: изменить (та же форма), снизить цену (окно), снять с продажи (причина + итоговая цена), вернуть в продажу
- Счётчики просмотров и сообщений

## Критерии приёмки
- [ ] Снятие с причиной «Продал на ЯМузыканте» и суммой создаёт sale_record; публично сумма не видна
- [ ] Снижение цены без повторной модерации; рост цены — тоже без модерации, но с записью в историю
- [ ] Вкладка в пороге эталона `account` (состояние listings — по чек-листу)
- [ ] Definition of Done — AGENTS.md §3
