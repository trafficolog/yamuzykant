# 2.1.4. Черновик, публикация, экран «Опубликовано»

## Цель
Объявление сохраняется черновиком и публикуется сразу после автопроверок (премодерация — флагом `premoderation`, с G2).

## Что сделать
- Автосохранение черновика каждые 5 с и при уходе со страницы
- «Сохранить черновик», «Опубликовать» → автопроверки 5.1.1 → published (с флагом `premoderation` → pending)
- Контакты в тексте — отправка заблокирована, у поля описания текст из SPEC UC-L1
- Экран «Объявление опубликовано» (с флагом — «Отправлено на проверку») с кнопками «Открыть объявление», «Продать ещё один»
- Форма после перезагрузки восстанавливается из черновика (серийный номер — маской, целиком на фронт не уходит); «Сохранить черновик» и автосохранение записывают неполную форму без обязательности (PUT /sell/draft)
- Лимит активных объявлений BR-06 (10, `config/listings.php`, активные = published + pending + needs_changes): публикация сверх лимита отклоняется с понятным текстом, черновик остаётся (по поручению оркестратора; состояние формы «Лимит: N из N» с советом — 2.1.6)
- Срок публикации — 60 дней (`listings.expire_after_days`), на экране «Объявление опубликовано»
- (ревью PR #126) Один черновик на пользователя гарантирован на уровне БД: частичный уникальный индекс `(user_id) WHERE status = 'draft'` (pgsql) или эквивалент, тест на настоящую гонку двух процессов
- (ревью PR #126) `CitySeeder` задаёт `settlement_type` только при создании записи, ручные правки не затираются
- (ревью PR #130) Перед `ListingStateMachine::publish()` и при правке опубликованного — `ListingAutoChecks::validate()`; блокирующие ошибки → 422 у полей; тест, что публикация с контактами в описании невозможна

## Критерии приёмки
- [ ] Перезагрузка страницы восстанавливает черновик с фото
- [ ] Двойной клик «Опубликовать» создаёт одно объявление
- [ ] После публикации объявление в кабинете со статусом «Опубликовано» и в Барахолке не позже 60 с; с флагом `premoderation` — «На проверке» и не в выдаче
- [ ] Публикация с контактами в описании невозможна; публикация без нужных фото и сверх лимита отклоняется, черновик остаётся
- [ ] Два процесса одновременно не создают второй черновик (БД отклоняет)
- [ ] Definition of Done — AGENTS.md §3
