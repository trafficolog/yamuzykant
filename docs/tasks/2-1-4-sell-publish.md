# 2.1.4. Черновик, публикация, экран «Опубликовано»

## Цель
Объявление сохраняется черновиком и публикуется сразу после автопроверок (премодерация — флагом `premoderation`, с G2).

## Что сделать
- Автосохранение черновика каждые 5 с и при уходе со страницы
- «Сохранить черновик», «Опубликовать» → автопроверки 5.1.1 → published (с флагом `premoderation` → pending)
- Контакты в тексте — отправка заблокирована, у поля описания текст из SPEC UC-L1
- Экран «Объявление опубликовано» (с флагом — «Отправлено на проверку») с кнопками «Открыть объявление», «Продать ещё один»

## Критерии приёмки
- [ ] Перезагрузка страницы восстанавливает черновик с фото
- [ ] Двойной клик «Опубликовать» создаёт одно объявление
- [ ] После публикации объявление в кабинете со статусом «Опубликовано» и в Барахолке не позже 60 с; с флагом `premoderation` — «На проверке» и не в выдаче
