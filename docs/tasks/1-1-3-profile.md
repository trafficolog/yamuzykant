# 1.1.3. Профиль, город и уведомления

## Цель
Пользователь меняет имя, город и уведомления; кабинет разделён на «Покупаю» и «Продаю».

## Что сделать
- `AccountLayout`: «Обзор»; группа «Покупаю» — Избранное (4.3.1), Сохранённые поиски (4.3.2, до G2 не выводится); группа «Продаю» — Объявления (2.1.5); «Сообщения» (4.1.2); «Профиль». Вкладки вне MVP — по флагам; вкладки ещё не сделанных задач не выводятся
- «Обзор»: блок «Покупаю» (избранное, непрочитанные чаты по чужим объявлениям) и блок «Продаю» (активные объявления, непрочитанные чаты по своим) — наполняются по мере готовности 2.1.5, 4.1.2, 4.3.1
- Вкладка «Профиль»: имя, город (автодополнение из справочника), почта входа — только просмотр, отметка «Яндекс ID подключён», переключатели уведомлений; смена почты — уточнить (отдельная карточка)
- Удаление аккаунта — заглушка до 6.3.2

## Критерии приёмки
- [ ] Имя показывается продавцом как «Имя» + «на ЯМузыканте с {месяц год}»
- [ ] Выключенное уведомление не отправляет письмо; служебные письма (код входа) уходят всегда
- [ ] Навигация кабинета сгруппирована «Покупаю» / «Продаю» (design/DEVIATIONS.md)
- [ ] Вкладка «Профиль» в пороге эталона `account` (состояние profile — по чек-листу)
- [ ] Definition of Done — AGENTS.md §3
