# 4.1.2. Сообщения: список и чат

## Цель
Экран сообщений по макету: список чатов слева, переписка справа.

## Что сделать
- `ConversationList`: поиск, фильтр «Покупаю / Продаю», архив, непрочитанные
- `ChatThread`: карточка объявления сверху, сообщения, системные сообщения, поле ввода (Enter — отправить, Shift+Enter — перенос), напоминание «платите после осмотра»
- «Написать продавцу» на лоте открывает или создаёт чат; гость — окно входа 1.1.2, после входа сразу открывается чат
- Ссылка «Сообщения» в шапке и в кабинете (1.1.3), счётчик непрочитанных
- Состояния: нет чатов, загрузка, ошибка отправки с повтором

## Критерии приёмки
- [ ] Экран в пороге эталона `messages`
- [ ] Отправка без сети показывает «Не отправлено · Повторить»
- [ ] Ссылки и телефоны в сообщении не кликабельны
- [ ] Definition of Done — AGENTS.md §3
