# 4.1.5. Сообщения: беседы всегда открыты, последнее состояние объявления, без архива

## Цель
По решению OWNER от 08.11.2026 (SPEC BR-10): начатая беседа открыта всегда, при любом статусе объявления; вверху беседы — последнее состояние объявления.

## Что сделать
- Убрать закрытие бесед: окно 30 дней и закрытие при `rejected`/`moderation` (`ConversationAvailability`, `SendMessage`, тексты 409 в lang); новая беседа — по-прежнему только по `published` (404)
- Конфиг `messaging.reply_window_days` и связанные тексты удалить; колонку `listings.unpublished_at` оставить (используется машиной состояний, безвредна) или удалить обратимой миграцией — обосновать в PR
- Список бесед: убрать фильтр «Архив» и пометку «Только чтение»; фильтры «Все / Покупаю / Продаю»
- Карточка объявления вверху беседы: миниатюра (обложка, не фото серийного номера), название, цена (BR-11), статус объявления для не `published` («Продано», «Снято с продажи», «Срок истёк», «На проверке», «Отклонено») — без причины снятия; для не `published` карточка не ссылка для собеседника-покупателя (страница 404), для владельца — ссылка
- Права на миниатюру: участник беседы видит обложку объявления не в `published` (правило в `PhotoVisibility`: участник беседы по этому объявлению, только обложка, `Cache-Control: private`); остальным — по-прежнему 404
- Быстрые ответы убрать из UI (бэклог 4.1.6)
- `closed_reason` из `ConversationResource` удалить; статус объявления — отдельным полем
- (ревью PR #137) `caution` не уходит отправителю: в broadcast — только получателю (отдельное событие в `private-user.{id}` получателя или без поля для отправителя); тест
- (ревью PR #137) Признак «просьба перейти в мессенджер» — как в объявлениях (`block_mention_only=false`, решение G1): только название вместе с ником, номером или идентификатором; «WhatsApp есть?» без ника — без признака
- (ревью PR #137) «Одинаковый текст в ≥ 5 чатах» — только для текстов длиннее порога из конфига (например 30 символов после нормализации), «Ещё продаётся?» не считается
- (ревью PR #137) `body_hash` — HMAC с ключом приложения вместо голого sha1; удалить мёртвый `Pending.posted` или использовать

## Критерии приёмки
- [ ] Ответ в беседе по снятому, истёкшему и отклонённому модератором объявлению проходит (тест)
- [ ] Покупатель в беседе видит миниатюру, название, цену и статус снятого объявления; посторонний не получает обложку (404) (тест)
- [ ] В UI нет «Архива», «Только чтение» и быстрых ответов (Vitest, e2e)
- [ ] Definition of Done — AGENTS.md §3
