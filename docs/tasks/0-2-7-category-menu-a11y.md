# 0.2.7. Меню категорий: доступность, высота подвала, скрытие доставки

## Цель
Меню категорий в шапке корректно читается скринридером и не теряет фокус (неблокирующие замечания ревью PR #79).

## Что сделать
- Роль меню — раскрывающаяся панель (`aria-expanded` у кнопки + `aria-controls`), а не `role="dialog"` без `aria-modal`; либо полноценный диалог с переносом фокуса — выбрать и обосновать в PR
- Заголовки внутри меню не нарушают иерархию страницы (нет `h2` раньше `h1`)
- Меню закрывается, когда фокус уходит за пределы самого меню, а не всей шапки
- Мобильная шторка категорий (6.1.1): перенос фокуса в шторку при открытии, захват фокуса, фокус не теряется при переключении вида «виды → группы → назад» (сейчас нажатый элемент скрывается `display:none`)
- `aria-label` вкладки «Сообщения» в MobileTabBar — из `lang/ru.ts`, без склейки в TSX
- `<meta name="viewport">` с `viewport-fit=cover` в `app.blade.php`, safe-area сверху у шторки — проверить на iPhone (эмуляция Playwright WebKit)
- Проверка высоты подвала в R1 на 390 px (931 ± 2 px) — защита от регрессии вместо визуального сравнения
- Флаг `delivery_service` (выключен): «Доставка с упаковкой» в подвале и «Доставка в защитной упаковке» в меню скрываются — доставка через службы после R1 (решение OWNER 03.11.2026); «Доставка» как способ передачи в объявлении не затрагивается

## Критерии приёмки
- [ ] axe без serious/critical при открытом меню; иерархия заголовков страницы — h1 первым
- [ ] На < 640 px фокус переносится в шторку при открытии, не уходит под неё по Tab и сохраняется при переключении видов
- [ ] Tab с последнего пункта меню на следующий элемент шапки закрывает меню
- [ ] Высота подвала на 390 px в R1 в пределах 931 ± 2 px (тест; значение пересчитать после скрытия доставки)
- [ ] При выключенном `delivery_service` ссылок на сервис доставки нет в шапке, меню и подвале (Vitest on/off)
- [ ] Definition of Done — AGENTS.md §3
