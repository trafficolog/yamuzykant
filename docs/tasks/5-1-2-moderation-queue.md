# 5.1.2. Модерация в консоли

## Цель
Модератор быстро проверяет объявления.

## Что сделать
- Filament-страница: очереди «Высокий риск», «Обычная», «Повторно»; фильтры; горячие клавиши (A — одобрить, R — вернуть, X — отклонить, J/K — следующее)
- Карточка проверки: фото крупно, флаги автопроверок, история продавца, прошлые решения
- Блокировка объявления за модератором на 10 мин (без двойной проверки)
- (ревью PR #130) Поиск дублей фото по pHash — отбор кандидатов в БД (префикс хеша / BK-дерево / расширение), а не перебор всех фото в PHP

## Критерии приёмки
- [ ] Состав страницы совпадает с макетом (чек-лист SCREENS.md §4)
- [ ] Два модератора не получают одно объявление одновременно
- [ ] Медиана времени решения видна на обзоре
- [ ] Definition of Done — AGENTS.md §3

## Тесты (пишутся первыми)
- Pest feature: выдача из очереди, блокировка, права
- Playwright: решение горячими клавишами

## Не делать
- Выходить за объём карточки
