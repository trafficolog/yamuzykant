# 4.1.4. Сообщения: текст не в журнал, доработки после ревью

## Цель
Текст сообщения не попадает в журнал и Sentry ни при каких ошибках; тесты домена проверяют то, что заявляют (неблокирующие замечания ревью PR #119).

## Что сделать
- `#[\SensitiveParameter]` на параметрах с текстом сообщения; ошибка сохранения перехватывается и заменяется своим исключением с кодом, без SQL и параметров (`QueryException` содержит текст)
- Тест «текст не попадает в задание очереди»: фильтровать задания с `MessageSent` и проверять каждое
- Тест на ветку гонки (`UniqueConstraintViolationException` при двух «Написать»)
- `MessageBody`: дополнительно убирать U+061C, U+2060–2064, U+206A–206F, U+00AD, хангыль-заполнители, U+FFF9–FFFB; U+2028/2029 → `\n`
- `/_e2e/messaging` и `/_e2e/photo-uploader` на stage и production — 404 для всех, включая гостя (сейчас редирект)
