# 2.1.9. Фото объявления: доработки после ревью

## Цель
Сбои обработки фото не оставляют мусор и непонятные ошибки, а ссылки на фото совпадают с правами раздачи (неблокирующие замечания ревью PR #109, круг 2).

## Что сделать
- `failed()` job обработки удаляет и частично записанные версии (`deleteDirectory($photo->path)`)
- Возврат лимита памяти: если `ini_set` не сработал — warning в журнал
- HEIC больше лимита ImageMagick по ширине или высоте → ошибка `dimensions` («не больше 50 Мп»), а не «сохраните как JPEG»
- `ListingPhotoResource` отдаёт ссылки только на фото, которые `PhotoMediaController` отдаст этому зрителю (одно правило для обоих), — до страницы лота 3.1.5

## Критерии приёмки
- [ ] После исчерпания попыток в бакете нет ни исходника, ни частичных версий (тест)
- [ ] Ссылки в Resource для гостя у не опубликованного объявления отсутствуют (тест)
- [ ] Definition of Done — AGENTS.md §3

## Тесты (пишутся первыми)
- Pest: failed() с частичными версиями, HEIC dimensions, Resource по статусам и ролям
