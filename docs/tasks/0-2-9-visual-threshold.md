# 0.2.9. Визуальные тесты: строгий порог для эталонов R1

## Цель
Сравнение с эталоном ловит реальные расхождения: сейчас порог 5 % площади всей страницы пропускает чужой экран целиком (ревью PR #128: копия прототипа прошла против реализации R1).

## Что сделать
- Для эталонов `*--r1@*`, снятых с реализации, — строгий порог (`maxDiffPixelRatio` ≈ 0.005) по умолчанию в хелпере; ослабление только явно и с обоснованием в коде
- Проверить существующие r1-эталоны (header, footer, flea, lot, sell, messages и др.): каждый снят с реализации, а не скопирован с прототипа (сверка sha256 с `design/screens/*@*.png` прототипа — тест)
- Маски динамики — только `[data-dynamic]`; документировать в docs/03-design
