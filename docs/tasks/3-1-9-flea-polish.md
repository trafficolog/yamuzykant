# 3.1.9. Барахолка: подпись цены без JS, e2e цены, позиция прокрутки

## Цель
«Договорная» и «Бесплатно» видны в SSR и без JS; возврат «Назад» сохраняет позицию (неблокирующие замечания ревью PR #117).

## Что сделать
- Заменить портал подписи цены в `FleaListingCard` на CSS: свойство `--price-label` на обёртке (строка из `lang/ru.ts`) и `.ym-price__now:empty::after { content: var(--price-label) }`; `ds/**` не трогать; доступное имя цены для скринридера — через видимый текст или `aria-label` обёртки
- e2e в браузере: лоты «Договорная» и «Бесплатно» — подпись видна до гидратации и после
- «Назад» после полной перезагрузки без bfcache: восстановление позиции прокрутки (`history.scrollRestoration` / сохранение в sessionStorage по ключу URL)
- Хвостовой `?` в адресе после редиректа на единственную страницу
- Запрос в репозиторий ДС: поддержка `price: null | 0` в `ListingCard` (после — убрать обёртку)

## Критерии приёмки
- [ ] В SSR-HTML лота с `price = null` есть «Договорная», с `price = 0` — «Бесплатно» (тест)
- [ ] После «Назад» с перезагрузкой страница открывается на прежней позиции (e2e)
- [ ] Definition of Done — AGENTS.md §3
