# 0.1.3. CI на GitHub Actions

## Цель
Все проверки из docs/02-process/CI-CD.md §2 работают на каждом PR и блокируют мерж.

## Что сделать
- Дописать `.github/workflows/ci.yml`: jobs `docs`, `php`, `js`, `e2e` с сервисами pgsql, redis, meilisearch
- Кэш composer, npm, браузеров Playwright; `concurrency` с отменой устаревших
- Пороги покрытия: общее ≥ 75 %, `app/Domain` ≥ 90 %
- Артефакты: отчёт Playwright, diff визуальных тестов, отчёт покрытия
- Включить обязательные проверки в защите `main` (`node tools/gh-sync.mjs --protection --apply`)

## Критерии приёмки
- [ ] PR с ошибкой Pint, Larastan, ESLint, tsc, Pest, Vitest или Playwright не мержится
- [ ] CI на пустом приложении ≤ 10 мин
- [ ] Тестовый PR с запрещённым словом в .tsx падает на job `docs`
- [ ] Отчёт Playwright скачивается из артефактов
- [ ] Definition of Done — AGENTS.md §3

## Тесты (пишутся первыми)
- Тестовые PR (закрыть без мержа): по одному на каждую проверку, доказательство — ссылки на красные run

## Не делать
- Не хранить реальные секреты в CI
