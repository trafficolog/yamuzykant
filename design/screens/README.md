# Эталоны

PNG-эталоны создаёт задача 0.2.3:

```bash
npx http-server design/prototypes -p 8123 &   # прототипам нужен http, не file://
node tools/capture-reference.mjs               # → design/screens/{id}@{1440|390}.png
```

Список экранов, состояния, маски динамических зон и пороги — `manifest.json`. Эталоны коммитятся в репозиторий. Перегенерация — только отдельным PR `chore(design): update references` с причиной: обновился макет или ДС.

Прототипы рисуют состояние по умолчанию. Остальные состояния из `states` проверяются e2e-тестами по описанию в `docs/03-design/SCREENS.md`. Если для состояния нужен свой эталон, исполнитель снимает его с реализации, OWNER подтверждает его на гейте, и снимок сохраняется как `{id}--{state}@1440.png`.
