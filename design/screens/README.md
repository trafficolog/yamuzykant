# Эталоны

PNG-эталоны создаёт задача 0.2.3:

```bash
npx http-server design/prototypes -p 8123 &   # прототипам нужен http, не file://
node tools/capture-reference.mjs               # → design/screens/{id}@{1440|390}.png
```

Список экранов, состояния, маски динамических зон, блоки и пороги — `manifest.json`. Эталоны коммитятся в репозиторий. Перегенерация — только отдельным PR `chore(design): update references` с причиной: обновился макет или ДС.

Прототипы рисуют состояние по умолчанию. Остальные состояния из `states` проверяются e2e-тестами по описанию в `docs/03-design/SCREENS.md`. Если для состояния нужен свой эталон, исполнитель снимает его с реализации, OWNER подтверждает его на гейте, и снимок сохраняется как `{id}--{state}@1440.png`.

## Детерминизм съёмки и сверки (0.2.6)

- Анимации и переходы отключены (`prefers-reduced-motion: reduce` и стиль `animation: none; transition: none`), шрифты дожидаются (`document.fonts.status === 'loaded'`) — и в `tools/capture-reference.mjs`, и в `openPrototype` (`tests/e2e/visual/_helpers.ts`).
- React для прототипов подкладывается из `node_modules` (та же 18.3.1, что runtime берёт с unpkg): иначе бандл ДС иногда выполняется раньше React, и прототип рисует ошибку вместо экрана. Прототип с ошибкой в консоли не снимается и не сверяется.
- Маски `mask` из manifest (например, `[data-dynamic]`) закрашиваются и в эталоне, тем же цветом, что при сверке `toHaveScreenshot`. В нынешних прототипах `[data-dynamic]` нет, поэтому маска ничего не закрашивает; она начнёт действовать, как только селектор появится.
- Если у экрана в manifest задан `block` (сейчас `header` и `footer`), эталон — снимок этого элемента, а не страницы на белом поле. Порог `maxDiffPixelRatio` считается от площади блока, белое поле его не разбавляет. Ширина эталона равна ширине viewport, высота — высоте блока.
- Версии `playwright`, `@playwright/test` и `http-server` закреплены точно: версия Playwright задаёт образ контейнера эталонов `mcr.microsoft.com/playwright:v{версия}-noble`. Обновляя её, обновите образ и пересними эталоны отдельным коммитом.
- Проект `references` идёт без ретраев (`retries: 0`).
- Эталоны состояния R1 (флаги вне MVP выключены, то, что видят пользователи): `header--r1@1440.png`, `footer--r1@1440.png`, `footer--r1@390.png`. Снимаются с реализации блоком (`header` / `footer`) в контейнере Playwright; объявлены в manifest (`stateReferences`), принимает OWNER на G1. Перегенерация — отдельным коммитом `chore(design)` с причиной.
- Общий код детерминизма (заморозка анимаций, React без CDN, ожидание шрифтов) — `tools/deterministic-page.mjs`, его используют и съёмка, и сверка.
