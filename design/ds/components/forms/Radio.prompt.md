Группа радиокнопок для выбора одного из 2–5 вариантов, которые важно видеть сразу: доставка, оплата, тип продавца.

```jsx
<Radio name="ship" label="Доставка" defaultValue="courier" options={[
  { value: "courier", label: "Курьер", hint: "Завтра, бесплатно" },
  { value: "pickup", label: "Пункт выдачи" },
  { value: "pack", label: "Доставка с упаковкой", hint: "Для инструментов" }]} />
```

`inline` — в строку. Подсказка под вариантом — `ink-muted`. Ошибка — под группой, текстом, не только цветом.
