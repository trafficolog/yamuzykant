Многострочное поле для свободного текста: описание лота, проблема для мастера, первое сообщение продавцу.

```jsx
<Textarea id="desc" label="Описание" maxLength={1000} hint="Что с грифом, электрикой, кейсом" />
<Textarea id="msg" label="Сообщение продавцу" rows={3} defaultValue="Здравствуйте! Гитара ещё продаётся?" />
```

Лимит мягкий: при превышении — ошибка и счётчик красным, но текст не обрезается. Высота растёт ручкой по вертикали.
