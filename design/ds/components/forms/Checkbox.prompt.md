Флажок для независимого выбора: фильтры в выдаче, «Только с безопасной сделкой», согласие с правилами.

```jsx
<Checkbox id="f-safe" label="Только с безопасной сделкой" defaultChecked />
<Checkbox id="f-all" label="Все бренды" indeterminate />
<Checkbox id="rules" label="Принимаю правила площадки" error="Без согласия опубликовать нельзя" />
```

Состояния: по умолчанию, наведение, фокус, отмечен, частично, неактивен, ошибка. Отмеченный — заливка `accent`, галочка `on-accent`. Подпись — утверждение, без точки.
