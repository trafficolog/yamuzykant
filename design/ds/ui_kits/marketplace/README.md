# Marketplace web — UI kit

Interactive desktop recreation of the screen briefs from the ЯМузыкант design-system artifact (раздел «Работа в Claude Design»): **Главная** (1), **Раздел вида: Каталог / Барахолка** (2), **Страница лота** (3), **Карточка модели** (3а), **Мастера** (7) + RepairOrderCard (8).

Everything is composed from `window.DesignSystem_b66810` components; `kit.css` adds only page layout (container, rails, filter sidebar, gallery, specs table, inverse footer). Photos are icon placeholders by design (brand book: no stock imagery until real lot photos exist). All numbers are examples.

Not built yet: «По рукам!» modal (4), checkout (5), «Продать гир» wizard (6), «Мои инструменты» (9), workshop cabinet (10), mobile 390 px.
