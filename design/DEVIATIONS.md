# Принятые отличия реализации от макетов

| Экран | Отличие | Причина | Принял (OWNER, дата) |
|---|---|---|---|
| console-* | Визуально — стандарт Filament, а не макет | Скорость MVP; состав и поведение соответствуют | предварительно, подтвердить на G2 |
| header | Своя композиция SiteHeader вместо Header ДС | В Header ДС нет города и меню категорий, есть запрещённое слово | предварительно |
| header | Окно входа: «Войти с Яндекс ID» + почта → код из письма → шаг «Имя, город, согласие» вместо «Почта или телефон» + пароль и выбора типа аккаунта | Решение OWNER 02.11.2026: вход через Яндекс ID и код на почту, без паролей и телефона; один аккаунт на покупку и продажу. Собирается из Button, Field, Checkbox ДС | предварительно, подтвердить на G1 |
| account | Навигация кабинета сгруппирована: «Покупаю» (Избранное, Сохранённые поиски — с G2), «Продаю» (Объявления), общие «Сообщения» с фильтром Покупаю / Продаю и «Профиль» | Решение OWNER 02.11.2026: один аккаунт, оба раздела | предварительно, подтвердить на G1 |
| sell | Экран после отправки — «Объявление опубликовано», пока выключен флаг `premoderation` | Публикация без премодерации до G2 | предварительно, подтвердить на G1 |
| home, flea, lot, seller, sell, help, error, header | Мобильная раскладка (390 px) не сверяется с эталоном — прототипы не адаптивны; приёмка по чек-листу SCREENS §3 и мобильному UI-киту ДС | Прототипы рисуют десктоп в узком окне | OWNER, 03.11.2026 |
| flea-empty | Пустое состояние Барахолки — из EmptyState ДС без эталона | Прототип `?empty=1` рисует обычную выдачу | OWNER, 03.11.2026 |
